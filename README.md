# Diel — páginas públicas

Las dos páginas que App Store Connect exige que sean accesibles públicamente:

- `index.html` — política de privacidad
- `soporte.html` — página de soporte

El código de la app vive en un repo aparte, privado. Este repo existe solo
porque GitHub Pages necesita ser público para servir el sitio.

Se generan desde el repo de la app con el mismo script que arma `docs/`.
Si cambian ahí, hay que copiarlas acá.
